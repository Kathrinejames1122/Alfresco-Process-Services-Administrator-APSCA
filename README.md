
# Alfresco Process Services Certified Administrator Certification Exam Guide

A dedicated study guide and technical reference repository for candidates preparing for the **Alfresco Process Services Certified Administrator (APSCA) Certification Exam**, covering process engine administration, security, deployment, and operational monitoring.

---

## Exam Overview

The Alfresco Process Services Administrator certification validates knowledge and practical skills related to administering enterprise process automation environments. Hyland's 2026 catalog lists the **Hyland Certified Alfresco Process Services Administrator Professional** certification.

  * **Exam Format**: The current official exam delivery format is not publicly specified.
  * **Target Audience**: Alfresco Process Services system administrators and IT professionals responsible for process engine operations and administration.
  * **Prerequisites**: No publicly verified prerequisite information was found for the current certification.

---

## Core Exam Domains & Knowledge Areas

The following study areas are based on Hyland's Alfresco Process Services administration documentation. They are not presented as an official published APSCA exam blueprint.

### 1. Process Services Architecture & Deployment

  * Process Services architecture, Process Engine components, and application structure.
  * Installation, deployment options, and container-based environments.
  * Database configuration and supported platform considerations.

### 2. Process Engine & Application Administration

  * Managing process applications, deployments, and process definitions.
  * Monitoring process instances, tasks, jobs, and execution status.
  * Using the Process Services Administrator application.

### 3. Security, Authentication & Identity Management

  * Authentication configuration and security settings.
  * LDAP and Active Directory integration.
  * User, group, tenant, and access administration.

### 4. Cluster Configuration & Monitoring

  * Configuring Process Engine clusters and administrator connections.
  * Monitoring cluster nodes, engine status, and operational metrics.
  * Managing deployments across environments and clusters.

### 5. Maintenance & Troubleshooting

  * Reviewing application logs and diagnosing operational issues.
  * Managing configuration, database connectivity, and service availability.
  * Investigating failed jobs and process execution problems.
